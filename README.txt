Privacidad:
La página incluye etiquetas noindex/nofollow/noarchive/noimageindex para reducir
su descubrimiento por buscadores. Esto NO es una contraseña ni control de acceso.

PUBLICACIÓN:
1. Subir los cuatro archivos a la rama main del repositorio.
2. GitHub → Settings → Pages.
3. En “Build and deployment”, seleccionar “Deploy from a branch”.
4. Branch: main.
5. Folder: / (root).
6. Pulsar Save.
7. Esperar la publicación de GitHub Pages.
8. Usar la URL final para crear el código QR.

IMPORTANTE:
El reproductor de Spotify puede requerir que Mafe pulse ▶ en el teléfono,
porque los navegadores móviles suelen bloquear la reproducción automática.
